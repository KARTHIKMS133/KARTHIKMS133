## 🚀 Featured Projects

### 1. Beacon — SaaS Subscription & Retention Analytics

**An end-to-end analytics project focused on subscription revenue, customer retention, and churn behavior.**

- Analyzed 36 months of simulated B2B SaaS data covering 1,831 accounts.
- Built MRR movement analysis, NRR/GRR metrics, and censoring-aware cohort retention.
- Developed RFM segmentation and a logistic regression churn model.
- Achieved 0.70 holdout AUC in the churn model.
- Built a four-page Streamlit and Altair analytics application.
- Verified SQL and Python metric parity with 28 automated checks.

**Selected findings from the analysis:**
- NRR ranged between 93% and 98%.
- Six-month retention declined from 78% to 71%.
- Accounts with less than 30% seat utilization represented 37% of MRR.

**Stack:** Python · Pandas · SQL · scikit-learn · Streamlit · Altair

[View Beacon Repository](https://github.com/KARTHIKMS133/beacon-saas-retention-analytics)
